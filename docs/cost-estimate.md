# 비용 추정 (AWS 프리 티어)

## 목표
- 월 과금 0원 또는 극소액 유지

## 기본 원칙
- EC2 1대만 운영
- 프리 티어 범위 내 리소스만 사용
- 비용 발생 가능 서비스(Fargate, ALB, NAT Gateway, RDS) 미사용

## 비용 점검 항목
- EC2 사용 시간/인스턴스 타입
- EBS 용량/스냅샷 사용량
- 공인 IPv4 사용량
- CloudWatch 로그 저장량
- Route53 사용 여부(도메인 비용)

## 알림 설정
- 예산(Budget): 0달러, 1달러, 3달러 경고
- 프리 티어 사용량 알림: 85% 임계값 알림

## 운영 규칙
- 사용하지 않을 때 인스턴스 중지
- 로그 보관 기간 짧게 유지
- 불필요 이미지/볼륨 정리

## 결과 기록 항목 (포트폴리오용)
- 월 비용 추이
- 비용 경고 발생 횟수
- 비용 최적화 조치 전/후 변화
